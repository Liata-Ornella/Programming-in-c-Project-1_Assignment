# Programming in C – Project 1 Assignment

## Overview

This repository contains my **Programming in C – Project 1 Assignment**. The project demonstrates basic C programming concepts, program compilation and execution, as well as an Arduino-based sensor monitoring activity.

The work includes solutions for Questions 1, 2, and 3, together with screenshots documenting the implementation and results.
